# MDB Studio

MDB Studio is a Windows desktop application project for viewing and editing Microsoft Access `.mdb` and `.accdb` databases.

Development will use **C# and WPF**, with source and build configuration published in this repository. Do not run or redistribute the earlier Go-based experimental EXEs; those were flagged by Microsoft Defender and have not been verified safe.

The first reviewed implementation and a GitHub Actions Windows build are being prepared in a separate branch. Builds are experimental until Windows and antivirus testing is complete.
